# TEZKOR DELIVERY

## Ishga tushirish (Windows)
`start.bat` faylini ikki marta bosing. Server ishga tushadi va admin panel brauzerda ochiladi.
Oynani yopmang: yopsangiz server to'xtaydi.

Yoki terminalda:  node server.js   ->  http://localhost:3000

- Sayt: http://localhost:3000   Admin: http://localhost:3000/admin.html
- Admin paroli: server.js ichidagi ADMIN_PASSWORD (internetga chiqarishdan oldin o'zgartiring va muhit o'zgaruvchisiga o'tkazing)
- Ma'lumotlar: data/db.json
- Live Server (5500) ishlatmang: u serverga ulanmaydi.
